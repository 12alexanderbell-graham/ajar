Close the lid. Keep working.

Ajar keeps your laptop awake with the lid shut while Claude Code, Codex and other agents run, then lets it sleep when they're done.

Download for Mac

Free · Mac (macOS 14+) · Windows (10 and 11) · Linux (x86-64)

Or: brew install --cask 12alexanderbell-graham/ajar/ajar · Open source on GitHub

First open: macOS asks before running apps from outside the App Store. Go to System Settings › Privacy & Security and click Open Anyway.

Only while work is happening

Awake while an agent is working, or while apps you pick are running, like an Xcode build. Sleeps a few minutes after.

Cuts the power that's wasted

With the lid shut it pauses what nobody's using (other apps, idle simulators, silent audio) and can switch the screen fully off. Real measured watts; everything comes back when you open the lid.

Stops before it hurts

Sleeps at your battery limit whatever else is going on, and if it gets too hot with the lid shut.

Check on it from your phone

See if it's still working, switch modes, or let it sleep, from anywhere. End-to-end encrypted.

  1. On the laptop: Ajar › Settings › Phone Control › Show QR Code.
  2. Scan it with your phone's camera.
  3. iPhone: tap Share, then Add to Home Screen.
    Android: tap ⋮, then Add to Home screen.

It then opens from your Home Screen like an app. Already paired? Open the phone page.

Let your AI set it up

Ajar connects to Claude Code, Codex and the Claude app in one click (or ajar connect). Then paste this and your agent tunes it with you: what stays on, what pauses, and what each saving is worth on your laptop.

Ajar is installed on this laptop. It keeps the machine awake with the lid closed while you work, and cuts power use while the lid is shut. You can control all of it through the ajar MCP tools (or the ajar command). Set it up for me:

1. Read Ajar's settings and power report to see every setting and what is using power right now.
2. Ask me, in one short message: which apps must keep running at full speed with the lid shut (music, calls, a local model, Docker...), whether it should stay awake only while agents work or always, and whether I'm OK with a lock screen when I open the lid in exchange for the screen turning fully off.
3. Apply the strongest savings that don't touch what I named: preset max_battery, pausing simulators and background audio, low power, and per-app rules.
4. If my lid is closed, run Ajar's power test and tell me what each saving is worth in watts.
5. From now on, keep the laptop awake through Ajar before long work and release it when done.

Never turn off the heat guard or lower the battery limit; Ajar won't let you, and that's on purpose.
